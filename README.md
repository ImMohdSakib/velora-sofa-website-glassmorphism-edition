# VELORA — Premium Sofa Store

React + Vite + Tailwind + Framer Motion luxury e-commerce UI.

## Features
- Glassmorphism premium UI
- Product collection with filters
- Cart & wishlist (localStorage)
- **Loading screen** on startup
- **Login / Sign up** (local accounts)
- **Checkout** — name, address, payment method
- **Order tracking** with status timeline
- Multi-page routing

## Run
```bash
npm install
npm run dev
```

## Demo flow
1. Sign up from user icon in navbar
2. Add sofas to cart → Checkout
3. Place order → Track from My orders
